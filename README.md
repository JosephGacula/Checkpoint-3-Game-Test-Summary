# Checkpoint-3-Game-Test-Summary

## Questions for Testers
* How does the character feel to control?
* Did you find it satisfying to kill enemies? If not what would help to make it satisfying?
* Does the color switching mechanic add to the gameplay? Do you see potential in it if fleshed out more?
* Any bugs or technical problems that you encountered?
* Any other suggestions for improving the game?

## Feedback from Subjects

### Subject 1
1. Controls need to be simplified. Character is way to sensitive. Wanted to play on a gamepad (was playing on keyboard)
2. Yes, it is satisfying to kill enemies. However, the enemies slipping around needs to be fixed. Could not tell enemies were enemies, sprites will have to be completed.
3. The color switch mechanic does have potential, just needs to be outlined and fleshed out more.
4. Yes. Floating when pressed up against platforms, enemies and projectiles triggering death and goal transitions.
5. Main suggestion was to make the control far less sensitive.

Note: Subject was not too familiar with games in general. Spend a lot of time trying to jump and move horizontally at the same time.

### Subject 2
1. Controls are sensitive. Otherwise figured out how to move, shoot, and slash pretty quickly. Wanted more specification on buttons used to color switch.
2. Yes. To make it more satisfying they need animations for being hurt and dying.
3. Yes, sees potential when polished and fleshed out further.
4. No bugs noticed.
5. Fixing sensitivity and enemy movement. Adding more animations and visuals.

### Subject 3
1. Controls are fluid but need to be toned down in terms of sensitivity. Have more of an introduction to the controls, whether it be on screen at all times or in sequence.
2. Not really satisfying. Have some sort of animation like them exploding or have damage visible.
3. Yes the color switch mechanic has potential.
4. No bugs. (When prompted more the subject said sticking to walls).
5. No suggestions. (When prompted more they said to just polish it up and add more content).

## Summary of Findings
The most common points of feedback was that the controls need work and more assets (sprites, animations, backgrounds) need to be created. In termss of controls, they are far to sensitive. Combined with the bug of enemies moving when pressed up against, this made it hard for them to try and kill things on first attempt. We will need to add gamepad support and polish physics to amend this problem. In terms of animations there was confusion on if they actually took damage or not. Sprites still need to be created for the enemies. Damage and death animations, as well as audio indicators of these will be added to fix this.
